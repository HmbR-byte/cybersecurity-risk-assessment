# Cybersecurity Risk Assessment

## Descripción
Ejercicio académico de identificación y valoración cualitativa de riesgos en una organización ficticia. Presenta activos, amenazas, vulnerabilidades y posibles controles de mitigación.

## Objetivo
Mostrar cómo se documentan riesgos de seguridad y se priorizan acciones según probabilidad e impacto.

## Contenido
- `matriz_riesgos.csv`: ejemplos de riesgos con clasificación cualitativa.
- `metodologia.md`: criterios y procedimiento de evaluación.

## Cómo consultar el proyecto
1. Lee `metodologia.md` para conocer las escalas utilizadas.
2. Abre `matriz_riesgos.csv` en Excel, LibreOffice o un editor de texto.
3. Compara el nivel de riesgo inicial con el control propuesto.

## Habilidades demostradas
Análisis de riesgos, documentación, priorización, seguridad de accesos y continuidad operativa.

## Alcance
Los datos y escenarios son ficticios; no corresponden a una evaluación real ni a una empresa identificable.
