# Metodología de evaluación

Se utiliza una matriz cualitativa simplificada. Cada riesgo recibe valores de **probabilidad** e **impacto** de 1 (bajo) a 3 (alto). El puntaje es el producto de ambos factores.

| Puntaje | Nivel |
| --- | --- |
| 1–2 | Bajo |
| 3–4 | Medio |
| 6–9 | Alto |

**Proceso:** identificar activo → describir amenaza y vulnerabilidad → valorar probabilidad e impacto → calcular nivel → recomendar controles → asignar revisión.

Este modelo es ilustrativo; una evaluación real requiere criterios organizacionales, responsables y evidencia verificable.
